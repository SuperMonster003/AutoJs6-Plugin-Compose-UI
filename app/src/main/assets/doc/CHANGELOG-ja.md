# v1.0.0

###### 2026/10/03

* `ヒント` P3 開発プレビュー: 呼び出し可能な compose / $compose, 29 個のノードファクトリー, 保持可能なハンドル, リアクティブな state/render/ref, batch/post/theme, UI スクリプトのマウント, raw またはサイズ変更可能なフローティングウィンドウを対応ローカル AutoJs6 ホストビルドで利用できます. 可用性確認, 型付きエラー, セッションの解放も含まれます. サンプル集, 完全な API 文書, 型宣言, より広い検証マトリクスは未提供です. 現在はローカルプレビューであり, 公式リリースではありません
* `ヒント` AutoJs6 6.8.0 (5316) 以降が必要です
* `新機能` プラグインリポジトリの骨格: プラットフォームバージョンプラグインのビルドチェーン, Jetpack Compose BOM 2026.09.00 の依存関係, Wake Activity による有効化プロトコル, INFO サービス (カテゴリ compose-ui)
* `新機能` JSON ソースから生成される 10 言語の README, プラグインセンターの説明, 更新履歴
* `新機能` プレビューはレイアウト, テキスト, アイコン, 画像, ボタン, 選択コントロール, スライダーに対応. 渡されたビットマップの所有権と解放責任は呼び出し元に維持
* `新機能` 全 20 種類の Modifier 操作で宣言順序を保持し, レイアウトスコープの検証, スクロール, アクセシビリティラベルに対応
* `新機能` Material 3 テーマはシード色, ライトとダークモード, Android 12+ のシステム動的色, フォント, 文字サイズ倍率に対応
* `新機能` 画面更新は一括適用され, 拒否時は直前の有効な画面を保持. 制御された入力はキュー経由のコールバックで変更を通知し, 終了時にコールバックを解放
* `新機能` プレビューの入力欄で選択範囲と IME の未確定文字列を保持し, フォーカスと明示的な編集に対応. 新しい入力を上書きする遅延編集は拒否
* `新機能` 安定した項目 key とインデックス指定スクロールを持つ遅延読み込みリスト, Scaffold とトップアプリバーのスロット, 制御型ダイアログ, 進捗インジケーター, 操作または終了結果をキュー順に返す Snackbar をプレビューに追加
* `新機能` スクリプトプレビューに呼び出し可能な compose / $compose, 29 個のノードファクトリー, 保持可能なハンドル, リアクティブな state/render/ref, バッチ処理, スケジュール実行, テーマ制御を追加
* `新機能` UI スクリプトから Compose 内容をマウント可能. 再マウントやスクリプト停止で古いセッションとコールバックを解放
* `新機能` 非 UI スクリプトから raw またはサイズ変更可能な Compose フローティングウィンドウを作成し, ピクセル単位の位置とサイズ, タッチとフォーカスを変更可能. ウィンドウ操作, floaty.closeAll, スクリプト終了による閉鎖に対応
* `改善` 可用性確認と ComposeError でプラグインの未導入, 無効, 未認証, 非互換, 権限不足, 終了済みセッションを統一報告. ネイティブウィンドウ接続前のキャンセルも解放処理で対応
* `依存関係` common-plugin-api.aar バージョン 6.8.0 (5307) を追加 (MPL 2.0, ハッシュ固定)
* `依存関係` Jetpack Compose BOM 2026.09.00 を追加 (Apache 2.0)
* `依存関係` AutoJs6 6.8.0 (5316) に対応する compose-ui-api.aar V1 を追加 (MPL 2.0, ハッシュ固定), 共有依存関係をホストと整合
* `依存関係` BOM 2026.09.00 で管理される Compose UI Test を追加 (Apache 2.0, テスト専用)
