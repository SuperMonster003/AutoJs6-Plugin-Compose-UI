# v1.0.0

###### 2026/10/03

* `Подсказка` Предварительная версия P3: вызываемые compose / $compose, 29 фабрик узлов, постоянные дескрипторы, реактивные state/render/ref, batch/post/theme и монтирование UI-сценариев работают с соответствующей локальной сборкой хоста AutoJs6. Плавающие окна по-прежнему запланированы на P3.4. Примеры в комплекте, полная документация API, объявления типов и расширенная матрица проверок еще не поставляются. Это локальная предварительная версия без официального выпуска
* `Подсказка` Требуется AutoJs6 6.8.0 (5316) или новее
* `Новое` Каркас репозитория плагина: сборочная цепочка плагина версий платформы, зависимости Jetpack Compose BOM 2026.09.00, протокол активации Wake Activity и сервис INFO (категория compose-ui)
* `Новое` README, описание для центра плагинов и журнал изменений на 10 языках, генерируемые из JSON-исходников
* `Новое` Предварительный рендерер поддерживает разметку, текст, значки, изображения, кнопки, элементы выбора и ползунки; переданные растровые изображения остаются во владении вызывающего кода, который отвечает за их освобождение
* `Новое` Все 20 операций Modifier сохраняют порядок объявления и поддерживают проверку области разметки, прокрутку и метки специальных возможностей
* `Новое` Темы Material 3 поддерживают исходный цвет, светлый и темный режимы, системные динамические цвета Android 12+, семейства шрифтов и масштаб текста
* `Новое` Обновления интерфейса применяются атомарно, а отклоненные сохраняют последний корректный вид; управляемые элементы ввода сообщают об изменениях через очередь обратных вызовов, освобождаемых при закрытии
* `Новое` Поля ввода предварительной версии сохраняют выделение и композицию IME, поддерживают фокус и явное редактирование, отклоняют запоздалые правки, которые перезаписали бы более новый ввод
* `Новое` В предварительную версию добавлены списки с устойчивыми ключами и прокруткой по индексу, слоты Scaffold и верхней панели, управляемые диалоги, индикаторы прогресса и очередь обратных вызовов действия или закрытия Snackbar
* `Новое` Предварительный API сценариев предоставляет вызываемые compose / $compose, 29 фабрик узлов, постоянные дескрипторы, реактивные state/render/ref, пакетные обновления, планирование и управление темой
* `Новое` UI-сценарии могут монтировать содержимое Compose; замена монтирования или остановка сценария освобождает старую сессию и обратные вызовы. Плавающее отображение запланировано на P3.4
* `Зависимость` Добавлен common-plugin-api.aar версии 6.8.0 (5307) (MPL 2.0, зафиксирован по хешу)
* `Зависимость` Добавлен Jetpack Compose BOM 2026.09.00 (Apache 2.0)
* `Зависимость` Добавлен compose-ui-api.aar V1 для AutoJs6 6.8.0 (5316) (MPL 2.0, фиксированная хеш-сумма), общие зависимости согласованы с хостом
* `Зависимость` Добавлен Compose UI Test под управлением BOM 2026.09.00 (Apache 2.0, только для тестов)
