# v1.0.0

###### 2026/10/03

* `Подсказка` Предварительная версия P5: вызываемые compose / $compose, 29 фабрик узлов, постоянные дескрипторы, реактивные state/render/ref, batch/post/theme, UI-монтирование и плавающие окна raw или с изменяемым размером работают с соответствующей локальной сборкой AutoJs6. Включены проверки доступности, типизированные ошибки и очистка сессий. В комплект входят пять примеров: счетчик, форма, список из 1000 элементов, плавающий HUD и темы. Они синхронизированы с категорией примеров Compose UI соответствующей сборки хоста. Проверки устойчивости, матрица совместимости на шести устройствах/эмуляторах и проверка упакованных приложений завершены; базовые показатели производительности зафиксированы. Полная документация API и объявления типов запланированы на P6. Это локальная предварительная версия без официального выпуска
* `Подсказка` Требуется AutoJs6 6.8.0 (5316) или новее
* `Новое` Каркас репозитория плагина: сборочная цепочка плагина версий платформы, зависимости Jetpack Compose BOM 2026.09.00, протокол активации Wake Activity и сервис INFO (категория compose-ui)
* `Новое` README, описание для центра плагинов и журнал изменений на 10 языках, генерируемые из JSON-исходников
* `Новое` Предварительный рендерер поддерживает разметку, текст, значки, изображения, кнопки, элементы выбора и ползунки; переданные растровые изображения остаются во владении вызывающего кода, который отвечает за их освобождение
* `Новое` Все 20 операций Modifier сохраняют порядок объявления и поддерживают проверку области разметки, прокрутку и метки специальных возможностей
* `Новое` Темы Material 3 поддерживают исходный цвет, светлый и темный режимы, системные динамические цвета Android 12+, семейства шрифтов и масштаб текста
* `Новое` Обновления интерфейса применяются атомарно, а отклоненные сохраняют последний корректный вид; управляемые элементы ввода сообщают об изменениях через очередь обратных вызовов, освобождаемых при закрытии
* `Новое` Поля ввода предварительной версии сохраняют выделение и композицию IME, поддерживают фокус и явное редактирование, отклоняют запоздалые правки, которые перезаписали бы более новый ввод
* `Новое` В предварительную версию добавлены списки с устойчивыми ключами и прокруткой по индексу, слоты Scaffold и верхней панели, управляемые диалоги, индикаторы прогресса и очередь обратных вызовов действия или закрытия Snackbar
* `Новое` Предварительный API сценариев предоставляет вызываемые compose / $compose, 29 фабрик узлов, постоянные дескрипторы, реактивные state/render/ref, пакетные обновления, планирование и управление темой
* `Новое` UI-сценарии могут монтировать содержимое Compose; замена монтирования или остановка сценария освобождает старую сессию и обратные вызовы
* `Новое` Сценарии без UI могут создавать окна Compose raw или с изменяемым размером, менять положение и размеры в пикселях, обработку касаний и фокус, закрывать окна их элементами управления, через floaty.closeAll или остановкой сценария
* `Новое` Пять исполняемых примеров: счетчик, проверка формы, список из 1000 элементов со стабильными ключами, плавающий HUD без режима UI и темы, с требованиями и индексом, синхронизированные с категорией примеров Compose UI соответствующего хоста
* `Исправление` Compose UI запрещает повторное монтирование страницы или плавающего окна внутри функции рендеринга и сохраняет текущую страницу; после обновления плагина страницы можно монтировать заново
* `Улучшение` Проверки и ComposeError единообразно сообщают об отсутствующих, отключенных, неавторизованных или несовместимых плагинах, нехватке разрешений и закрытых сессиях; очистка охватывает окна, отмененные до нативного подключения; Обновление, удаление или отключение плагина закрывает активные сеансы с соответствующей ошибкой
* `Зависимость` Добавлен common-plugin-api.aar версии 6.8.0 (5307) (MPL 2.0, зафиксирован по хешу)
* `Зависимость` Добавлен Jetpack Compose BOM 2026.09.00 (Apache 2.0)
* `Зависимость` Добавлен compose-ui-api.aar V1 для AutoJs6 6.8.0 (5316) (MPL 2.0, фиксированная хеш-сумма), общие зависимости согласованы с хостом
* `Зависимость` Добавлен Compose UI Test под управлением BOM 2026.09.00 (Apache 2.0, только для тестов)
* `Зависимость` Добавить JaCoCo версии 0.8.14 (только для необязательного измерения покрытия тестами, не входит в пакеты выпуска)
