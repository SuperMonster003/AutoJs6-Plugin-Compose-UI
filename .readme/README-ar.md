### مقدمة

******

3-Block Compose هي إضافة لعرض الواجهات في AutoJs6. تعلن النصوص عن الواجهات عبر `compose` / `$compose` التي يوفرها المضيف, وتعرضها الإضافة داخل عمليته باستخدام Jetpack Compose وMaterial 3. تدعم المعاينة محتوى أنشطة `"ui";` والنوافذ العائمة للنصوص غير UI.

يتضمن المكون الإضافي مصمما مرئيا ومعرض مكونات: فتحه من المشغل يؤدي إلى الصفحة الرئيسية للمصمم حيث تنشأ مشاريع السكربتات أو تستورد وتحرر على العارض الحقيقي, بينما يعرض المعرض معاينات وسكربتات أمثلة لكل مكون; ولا تزال واجهات السكربتات تعرض داخل عملية المضيف. يكتشف المضيف المكون الإضافي عبر خدمة INFO ويقرأ إصداره ومعلومات توافقه, ثم ينشئ مصنع العارض داخل عمليته وفق العقد (`org.autojs.plugin.compose.api`).

### الحالة الحالية

******

معاينة تطوير محلية 1.3.0: تتطلب بناء مضيف AutoJs6 يحمل هوية 3-Block Compose الجديدة (التزام المضيف f12665ffde أو ما بعده) مع تثبيت هذا المكون الإضافي وتفعيله; ويتطلب عنصر قائمة محرر AutoJs6 "فتح في مصمم 3-Block Compose" بناء لاحقا لالتزام المضيف db7e6a1734. توفر الحزمة المحلية صفحات واجهة المستخدم, والنوافذ العائمة, والمصمم المرئي, وخمسة أمثلة, ومرجع API, وصفحة دليل المصمم, وتعريفات TypeScript. نطاق التوافق والأداء المتحقق منه مسجل في خارطة الطريق. غير مسجل بعد في الفهرس الرسمي; ولا يوجد إصدار رسمي. تستخدم الأيقونات الرسم النهائي من المشرف.

### الميزات

******

قدرات معاينة التطوير الحالية:

- مصمم مرئي: ملف السكربت هو المشروع, ويعرض العارض الحقيقي شجرة الواجهة أثناء التحرير, ويغطي المخطط / لوحة المكونات / درج الخصائص جميع المكونات الخمسة والخمسين, مع التراجع / الإعادة واستعادة المسودات; يمكن نسخ السكربت المصدر أو إرساله مباشرة إلى AutoJs6
- الربط مع AutoJs6: يمكن إرسال المشروع للتشغيل, أو فتحه في محرر AutoJs6 (مزامنة في الاتجاهين), أو استيراده إلى مجلد سكربتات AutoJs6, أو نسخه أو تصديره; كما يفتح المصمم ملفات .js مباشرة من محرر AutoJs6 أو مدير الملفات ويحفظ في الملف نفسه
- واجهة تصريحية: يعيد `compose.state` + `compose.mount(render)` الرسم تلقائيا عند تغير الحالة, بينما تتيح مقابض العقد طويلة العمر (`compose.Text({...})` وأمثالها) تعديل الخصائص والعقد الفرعية مباشرة
- نواة Material 3: توفر 29 دالة لإنشاء عقد التخطيط والنصوص والأيقونات والصور والأزرار والإدخال والاختيار والقوائم الكسولة والحوارات والتقدم; Snackbar أمر للجلسة وليس دالة إنشاء compose.Snackbar
- سلاسل Modifier: يحافظ `compose.modifier().padding(16).fillMaxWidth().background('#FFFFFF')` على ترتيب العمليات, ويتحقق المضيف من العمليات المقيدة بالنطاق
- طريقتان للعرض: `compose.mount` أو استدعاء `compose` / `$compose` لمحتوى أنشطة `"ui";`, و`compose.floaty` للنوافذ العائمة raw أو القابلة لتغيير الحجم, بما في ذلك النصوص غير UI
- العرض داخل عملية المضيف: تطبق تحديثات الواجهة داخل المضيف وتوضع الأحداث في طابور خيط البرنامج النصي المالك; تستخدم خيوط العمل compose.post لطلب التحديث
- يتضمن APK واحد arm64-v8a / armeabi-v7a / x86_64 / x86 دون شيفرة أصلية خاصة بالإضافة; تتضمن الحزمة مكتبة AndroidX graphics-path المساعدة وتظل شروط توافق Android والمضيف والإضافة مطلوبة
- يحافظ تحرير النص الأصلي على التحديد وتركيب IME ويدعم التركيز والتعديلات الصريحة ويرفض التعديلات المتأخرة التي ستستبدل إدخالا أحدث; يتحكم البرنامج النصي بحالة المفاتيح وشرائط التمرير
- حماية التكامل: تشير الفحوص إلى عدم التوفر عند غياب الإضافة أو عدم توافقها, وتستخدم الأخطاء `ComposeError`, ويحرر إغلاق الجلسة أو إيقاف النص نوافذها واستدعاءاتها الراجعة
- خمسة أمثلة قابلة للتشغيل للعداد والتحقق من النموذج وقائمة من 1000 عنصر بمفاتيح ثابتة وHUD عائم خارج وضع UI والسمات, مع المتطلبات والفهرس ومزامنتها مع فئة أمثلة 3-Block Compose في المضيف المطابق
- يدعم TSX الصيغ `<compose.Column>` و `<compose:Text>` ومراجع مصانع العقد و Fragment والخانات والاستدعاءات التفاعلية. لا يمكن خلط عقد Compose وعقد XML القديمة في شجرة واحدة
- تدمج حاويات XML `<compose>` و compose.attach جلسات Compose مستقلة في صفحات UI أو النوافذ العائمة الحالية. يعرض compose.AndroidView عنصرا جاهزا من Android View أو عنصرا تعيده دالة إنشاء متزامنة
- تعيد compose.dialog جلسة قابلة للتحديث والإغلاق للحوارات واللوحات السفلية المشروطة في نصوص UI والنصوص العادية
- مكونات Material 3 الموسعة: التنقل والأدراج وعلامات التبويب واللوحات السفلية والقوائم واختيار التاريخ والوقت والصفحات والشبكات والشرائح والشارات والأزرار المجزأة والعائمة والبحث والتلميحات والسحب للتحديث
- معرض المكونات: يعرض مدخل المشغل معاينات Material 3 وسكربتات أمثلة قابلة للتشغيل لجميع المكونات الـ 55, ويمكن نسخها أو إرسالها إلى AutoJs6; وتتبع صفحة الإعدادات لغة AutoJs6 ووضعه الداكن ولون سمته افتراضيا وتوفر أربع أيقونات للمشغل

### طريقة الاستخدام

******

1. ثبت بناء محليا مطابقا من AutoJs6 يتضمن نقطة دخول نصوص compose (الحد الأدنى 6.8.0 / 5322)
2. ثبت ملف APK للمكون الإضافي; افتح 3-Block Compose من المشغل للوصول إلى الصفحة الرئيسية للمصمم, وأنشئ مشروع سكربت, أو افتح معرض المكونات والإعدادات من الشريط العلوي
3. تأكد في مركز الإضافات في AutoJs6 من أن 3-Block Compose معروفة ومفعلة
4. استخدم `compose` أو `$compose` في النصوص; ركب الأنشطة عبر `compose.mount`, أو امنح المضيف إذن العرض فوق التطبيقات واستخدم `compose.floaty`
5. توفر قائمة شاشة التحرير التشغيل, والفتح في محرر AutoJs6, والاستيراد إلى سكربتات AutoJs6, والنسخ, والتصدير; واختيار 3-Block Compose من قائمة محرر AutoJs6 (يتطلب نسخة AutoJs6 تتضمن التحديث المقابل) أو من مدير الملفات يحرر ملف السكربت مباشرة

### بداية سريعة

******

يمكن تشغيل العداد وHUD العائم أدناه مع مضيف المعاينة المحلي المطابق. امنح المضيف إذن العرض فوق التطبيقات الأخرى قبل تشغيل HUD:

```js
"ui";

// عداد (طبقة render التصريحية)
let count = compose.state(0);

compose.mount(() => compose.Column({ modifier: compose.modifier().fillMaxSize().padding(16), spacing: 12 }, [
    compose.Text({ key: 'counter', text: `تم النقر ${count.value} مرة`, style: 'headlineSmall' }),
    compose.Button({ key: 'inc', onClick: () => { count.value += 1; } }, 'أضف واحدا'),
]));
```

```js
// HUD عائم (طبقة مقابض العقد)
let worker = null;
let status = compose.Text({ text: 'جار التحضير...', color: '#FFFFFF' });
let win = compose.floaty(compose.Column({ padding: 12, bg: '#CC000000' }, [
    status,
    compose.TextButton({ contentColor: '#FFFFFF', onClick: () => win.close() }, 'إغلاق'),
]), { x: 50, y: 300, raw: true });
win.on('close', () => { if (worker) worker.interrupt(); });

worker = threads.start(() => {
    for (let i = 1; i <= 100; i++) {
        sleep(1000);
        compose.post(() => {
            if (!win.isClosed()) status.text = `التقدم ${i}%`;
        });
    }
});
```

تسرد assets/examples/index.json خمسة برامج نصية قابلة للتشغيل وتزامنها مع فئة 3-Block Compose في المضيف المطابق. تشرح مقدمة كل مثال الوضع والأذونات. استخدم مرجع API المحلي وتعريفات TypeScript/المحرر المرافقة لتفاصيل العقد والمعدلات والسمات والجلسات والنوافذ; قد لا يتضمن الموقع هذه التغييرات المحلية بعد.

### الأسئلة الشائعة

******

- كيف تعمل أمثلة المعرض? يسلم "تشغيل في AutoJs6" السكربت إلى AutoJs6 المثبت; أما المعرض نفسه فيعرض المعاينات والكود فقط ولا ينفذ السكربتات
- هل يستطيع المصمم فتح أي سكربت? إنه يفسر فقط تصريحات `compose.state` في المستوى الأعلى واستدعاء `compose.mount` / `floaty` / `dialog` الوحيد; وتبقى بقية العبارات كما هي. الأشكال التي لا يمكن ربطها (جذر ليس مصنع compose, عدة استدعاءات تركيب, دالة عرض بدون return) ترفض مع ذكر السطر والعمود
- هل يشغل المصمم السكربتات? لا. إنه يحللها بمحلل Rhino فقط ويعاينها بعارض المكون الإضافي نفسه; لا تنطلق الأحداث وتعرض state قيمتها الأولية. التشغيل متروك لـ AutoJs6
- لماذا لا يوجد `compose`? يوفر البناء المحلي المطابق للمضيف هذا الكائن العام; تثبيت APK الإضافة وحده لا يضيفه
- هل يلزم إلغاء تثبيت إضافات الواجهة الأخرى? لا, فإضافة 3-Block Compose لا تتعارض مع وحدة `ui` الحالية ولا مع الإضافات الأخرى
- ماذا يحدث عند تغيير الإضافة? يؤدي تحديثها أو إزالتها أو تعطيلها إلى إغلاق الجلسات النشطة والإبلاغ عن الخطأ المقابل; تسمح الإضافة المتوافقة والمفعلة بتركيب جديد
- ماذا تتطلب النوافذ العائمة? امنح المضيف إذن العرض فوق التطبيقات واستدع `window.requestFocus()` قبل إدخال النص. إذا لم يعرض HyperOS النافذة, عد إلى سطح المكتب. يعيد غياب الإذن PERMISSION_REQUIRED دون فتح طلب ترخيص تلقائي
- هل يمكن استخدام TSX أو أي دالة Compose? يمكن استخدام مصانع عقد Compose الموثقة مع المضيف و TypeScript Engine المطابقين. لا يدعم دوال Kotlin Composable العشوائية أو مكونات TSX المخصصة
- هل يفقد التدوير الحالة? يعالج المضيف الحالي تغييرات الاتجاه العادية مع الاحتفاظ بمحرك البرنامج النصي. إعادة إنشاء Activity فعليا أو إتلافها يغلق المحرك وجلساته; لا تستعاد حالة العمل تلقائيا
- كيف تعثر المحددات على المكونات? يعرض testTag كمعرف ID أصلي دون بادئة حزمة. تختلف id/testTag عن desc/contentDescription; قد يكون نص Button عقدة فرعية لذا اتبع parent() إلى سلف قابل للنقر عند الحاجة

### الأذونات والأمان

******

لا تطلب الإضافة أي أذونات وقت تشغيل من Android ولا تصل أبدا إلى الشبكة أو التخزين أو المستشعرات.

- حماية المكونات: Wake Activity وخدمة INFO محميان بصلاحية التوقيع `org.autojs.permission.PLUGIN`, فلا يصل إليهما سوى مضيف AutoJs6; أما شاشة تحرير المصمم فهي مكون مصدر بلا صلاحية لا يقبل إلا Uri مستند سكربت يسلمه المستخدم, وتقتصر القراءة والكتابة على ذلك الـ Uri
- السلوك في الخلفية: لا يملك المكون الإضافي خدمة دائمة ولا مهام مجدولة, ويتلقى بثا واحدا من النظام عند تحديثه فقط لضبط مكونات أيقونة المشغل; ولا يستهلك شيئا ما لم يحمله المضيف وما دام المصمم والمعرض مغلقين
- حدود البيانات: لا يقرأ العارض بيانات السكربتات أو ملفات المستخدم ولا يكتبها, وحالة الواجهة لا توجد إلا في ذاكرة عملية المضيف; تحفظ مشاريع المصمم ومسوداته في المجلد الخاص بالمكون الإضافي, ولا تستورد أو تصدر إلا عبر منتقي المستندات في النظام, أو تقرأ وتكتب ملف سكربت واحدا عبر Uri يسلمه المستخدم; ولا يشارك مجلد المشاريع إلا عبر موفر المحتوى الخاص بالمكون الإضافي, لكل طلب, عند تسليم مشروع إلى AutoJs6; يحتفظ الاستيراد بصلاحية الوصول إلى الملف المختار إذا سمح مزوده بذلك, لكن لا يقرأ الملف أو يكتب إلا عندما يختار المستخدم "الكتابة إلى المصدر" أو "إعادة الاستيراد من المصدر"
- سياسة النسخ الاحتياطي: النسخ الاحتياطي للتطبيق والنقل بين الأجهزة معطلان, ولا تحتفظ الإضافة بأي بيانات تستحق الترحيل

عند تحميل المعرض يحتفظ المضيف بنموذج أذونات السكربتات الخاص به; لا توسع الإضافة قدرات النظام التي يمكن للسكربتات الوصول إليها.

### البناء

******

بعد الاستنساخ, ابن مباشرة باستخدام Gradle Wrapper; تختار إضافة إصدارات المنصة إصداري Android Gradle Plugin و Kotlin تلقائيا وفق بيئة IDE الحالية.

بناء حزمة APK للتصحيح:

```powershell
.\gradlew.bat :app:assembleDebug
```

تشغيل اختبارات وحدة JVM وتعبئة اختبارات العقد على الجهاز:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebugAndroidTest
```

بناء حزمة APK للإصدار (يتطلب `sign.properties` ومفتاح التوقيع):

```powershell
.\gradlew.bat :app:assembleRelease
```

التحقق من التوقيع وإنتاج ملف الإصدار مع لاحقة الملخص:

```powershell
.\gradlew.bat :app:appendDigestToReleasedFiles
```

التحقق من مطابقة المستندات المترجمة لمصادرها:

```powershell
py .python\generate_markdown.py --check
```

يتطلب البناء JDK 21 أو أحدث. بعد تعديل المصادر تحت `.readme` أو `.changelog`, شغل `py .python\generate_markdown.py` لإعادة توليد جميع المستندات.
